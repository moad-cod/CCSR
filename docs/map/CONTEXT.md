# CCSR System Map

This is a change-impact index, not a second implementation specification.

- [`objects/`](objects/) contains important nouns and their authoritative
  sources.
- [`processes/`](processes/) contains real movements through the current system.

Each card records current implementation status, source links, and first-order
impact using **Hits** and **Does not hit**. Planned objects are explicitly marked
and cite the registries or maps used to verify their absence.

The source code and Alembic migrations remain authoritative. Do not copy field-
by-field schemas, endpoint bodies, configuration values, or operational state
into these cards.
