# Evaluation context

The implemented evaluation packages compare RAG ingestion through Airflow and
Celery. They are RAGForge research assets, not a generic platform experiment
model.

- `airflow_benchmark/` and `celery_benchmark/` contain executable benchmark
  clients, validation, metrics, and report generation.
- `configs/` contains benchmark inputs.
- `legacy/` is retained for reproducibility and has optional dependencies.

Do not present these packages as generic CCSR studies or experiments until
durable research entities and execution contracts exist.
